# CPU66 timing experiment24: select the FPU frame address before vector classification

Both experiment22 seeds and experiment23 pre-read have a critical FRESTORE header → FPU format exception → WB exception-address selection path. The frame address defaults to the instruction PC; FRESTORE does not replace it. Special FPU addresses are already selected in the FPU interface only for their corresponding exceptions.

This candidate selects the FPU address for every FP uop, without waiting for the vector to become nonzero. The preceding instruction-fetch fault, operand fault and odd-target priorities remain. FP odd-target checking uses the actual conditional FBcc/FDBcc target and raw predicate, avoiding unreachable integer-unconditional branch combinations. Vector, frame, commit, hold and exception priority behavior is preserved.

Both variants pass185 CPU cases and four adapter runs with exact parent cycles. An independent simulation-only register model calculates the complete original WB address every cycle, including the later store and maintenance-fault overwrites. Every initialized value is checked, including unused values. The old odd-target expression is also checked on every valid EX uop. Static inspection finds226 explicit FPU micro-ops:224 have no branch and two are conditional. Dynamic EOP micro-ops have no branch. Runtime assertions check the same branch restriction.

A targeted test changes the existing BSUN branch to a signaling-true predicate with an odd destination: BSUN must retain priority over odd-target handling. All five bus configurations pass with exact parent cycles. The slowest test checks187,764 WB address cycles,42,279 valid FPU odd checks and61 advancing FRESTORE header operations. [Small validation](perf/cpu66_20261022/timing24/small/validation.json), [pre-read validation](perf/cpu66_20261022/timing24/preread/validation.json).

The small variant retains the original five physical RF read ports; pre-read retains21's six. Each is its corresponding23 archive plus the preserved backend patch. All26 CPU files match the tested scratch tree byte-for-byte. Balanced seed38 fits use66/33/99MHz, stamp261023 and duplication OFF, with four tag-M10K and25/30 RF-MLAB inference guards. No explicit register, stage, cycle or timing exception is added. The fits are running in separate directories. No timing improvement or hardware qualification is claimed yet. No VRAM changes are included.
