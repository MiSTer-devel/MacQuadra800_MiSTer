# CPU66 timing experiment25: register FPU operand decisions

Experiment23 pre-read has a -1.776ns internal FPU path from the working significand through a wide equality reduction and result selection back to the significand. Wide comparisons also select binary operand swapping and exact multiply/divide shortcuts. This follow-up to24 inserts F_CMP before F_BIN, registering five decisions: both power-of-two predicates, full significand equality, operand swap, and unsupported destination datatype. No wide data register bank is added.

The operand data remains unchanged in F_CMP. Every F_BIN entry checks all five flags against the original expressions on its current operands. The full FPU witness exercises164 such entries, including restored-frame arithmetic. FSGLMUL retains its existing chopped power-of-two predicate; FSGLDIV retains full-width comparisons. All six entries to F_BIN, including source-conversion shortcuts and square root, now pass through F_CMP. The acceptance and writeback flags remain false during that extra cycle.

This deliberately trades one additional FSM cycle per binary FP or square-root operation for a shorter combinational decision path. It does not add a CPU pipeline stage. Both RF-port variants pass185 CPU cases and four adapter runs. The variants have identical CPU cycle counts to each other;165 cases retain the parent24 count and20 FPU-related cases change. Results, exception-frame checks and adapter beat counts pass. The slow FPU workload rises from188,073 to188,201 cycles (0.068% for that particular mixed test; this is not a hardware benchmark).

The pre-read variant retains six RF ports and the small variant retains five. Each pinned source is its matching24 archive plus the FPU patch, byte-verified against the tested tree. The global fit, including ALMs, all setup and hold clocks and related-clock crossings, must decide whether this is useful.
