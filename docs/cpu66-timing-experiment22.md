# CPU66 timing experiment 22: combine index pre-read with the overwritten operand-bypass removal

Experiment20's actual worst path is FPSR pending-exception classification through full EX write qualification into AG's operand mux, then DC1 B. When AG advances, a later nonblocking assignment already broadcasts EX's value with `exw_fw`, whose condition includes every `exw_v` case. The earlier full bypass is overwritten before the operand is consumed.

The candidate removes that earlier bypass when EARLY_RES=0 (the actual core configuration), retaining it unchanged for the optional AG early-result ALU. This is experiment21 plus [operand-bypass.patch](perf/cpu66_20261022/timing22/operand-bypass.patch), a one-condition change with no new state or array beyond21's extra read port. Experiment13 tested the same removal alone and regressed globally, as did the earlier combined15 fit; the current measured worst path and21's separate AG index-path change justify testing this combination. A new fit is required; the older results are not treated as a win.

All185 CPU cases and four adapters pass with exact experiment21 cycles. The original experiment13 operand observer is restored in the scratch [checks](perf/cpu66_20261022/timing22/checks.sv): full-forward implies short-forward, and both complete operand values after assignment priority equal the old rules. The FPU stress witness checks27,002 operand pairs and120,770 index reads. An additional25 cases with EARLY_RES=1 pass (early results, integer, MOVEM restart, cache and FPU across five bus configurations), checking the retained optional bypass. [Validation](perf/cpu66_20261022/timing22/validation.json).

The prototype remains in scratch while preceding fits run. A pinned composite archive contains the tested21 source plus this backend file.
